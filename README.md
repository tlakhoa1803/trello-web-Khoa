# 🧩 Trello Clone App

A modern **Trello Clone** built using **React + Vite** that replicates the core features of Trello's kanban board — including cards, columns, and dynamic UI interactions.

---

## 🚀 Features

- 🔹 Create and delete columns dynamically
- 🧱 Add new cards to columns
- 📝 Display card details like title, members, comments, views
- 💅 Smooth, responsive UI with TailwindCSS
- 🌙 Light/Dark mode toggle (UI only)
- 🎨 Inspired by Trello's board layout

---

## 🛠️ Tech Stack

- ⚛️ React
- ⚡ Vite
- 💨 Tailwind CSS
- 🧠 Zustand / Context API (for state management) *(tuỳ bạn dùng gì)*
- 🧩 FontAwesome / Lucide Icons

## 📦 Installation

```bash
# 1. Clone the repo
git clone https://github.com/tlakhoa1803/trello-web-Khoa.git

# 2. Move into the project folder
cd trello-clone

# 3. Install dependencies
npm install

# 4. Run development server
npm run dev
